# 03. Глобальная конфигурация

Глобальные ключи действуют на любой команде и должны указываться
**до** имени подкоманды (или — благодаря `cobra` — между группой и
подкомандой). Большинство ключей имеют альтернативу в виде переменной
окружения; флаг командной строки имеет приоритет над окружением, а
окружение — над встроенными значениями по умолчанию.

## Сводная таблица

| Флаг | Переменная окружения | По умолчанию | Назначение |
|------|---------------------|--------------|-----------|
| `--network <id>` | — | `mainnet` | Целевая сеть TRON: `mainnet` или `shasta`. |
| `--output <fmt>` | — | `table` | Формат вывода: `table` (для человека) или `json`. |
| `--http-url <url>` | — | по сети | Переопределить базовый URL HTTP API TronGrid. |
| `--grpc-url <host:port>` | — | по сети | Переопределить адрес gRPC полного узла. |
| `--api-key <key>` | `MONUJO_TRONGRID_API_KEY` | пусто | API‑ключ TronGrid для повышенных лимитов запросов. |
| `--keystore-dir <path>` | `MONUJO_KEYSTORE_DIR` | `~/.config/monujo/keystore` | Каталог зашифрованных файлов кошельков. |
| `--version` | — | — | Показать версию и git‑коммит, заложенные при сборке. |
| `--help` / `-h` | — | — | Справка `cobra` по команде или подкоманде. |

Дополнительные переменные окружения, не имеющие парного флага:

| Переменная | Где используется | Назначение |
|------------|------------------|-----------|
| `MONUJO_IMPORT_KEY` | `wallet import` | Альтернатива `--key-hex`: 64 hex‑символа приватного ключа. |
| `MONUJO_TRON_E2E` | Только в `make test-integration` | Включает реальные интеграционные тесты с настоящими узлами Tron. На обычное использование CLI не влияет. |

## Описание каждого ключа

### `--network`

Тип: строка. Допустимые значения:

- `mainnet` (по умолчанию) — основная сеть TRON.
- `shasta` — публичная тестовая сеть Shasta.

Регистр не важен (`Mainnet`, `SHASTA` тоже валидны), но в файле
keystore сеть всегда хранится в нижнем регистре.

Ошибка: `unknown network "..." (use mainnet or shasta)`.

Этот выбор определяет:

- HTTP‑эндпойнт TronGrid (см. [07 — Сети](07-networks.md));
- адрес gRPC‑узла;
- адрес контракта USDT;
- запись в метаданных `networks` keystore при `wallet create`/`wallet import`
  и при успешной отправке через `hot send-*`;
- срабатывание интерактивного предупреждения при несоответствии
  сетей у уже использованного кошелька.

### `--output`

Тип: строка. Допустимые значения:

- `table` (по умолчанию) — человеко‑читаемый текст.
- `json` — машинно‑читаемый JSON, годный для `jq`/скриптов.

Регистр не важен. Ошибка: `unknown output format "..." (use table or json)`.

Подробнее о форматах — в каждом из разделов про команды.

### `--http-url`

Тип: строка (URL). По умолчанию подставляется один из:

- `https://api.trongrid.io` (mainnet)
- `https://api.shasta.trongrid.io` (shasta)

Используется для `watch balance`, `watch txs`, `hot balance`. Если
указать пустую строку — действует значение по умолчанию.

Ведущий и завершающий пробелы обрезаются, завершающий `/` тоже
обрезается. Никакой авто‑префиксации `https://` нет — указывайте URL
полностью.

### `--grpc-url`

Тип: строка `host:port`. По умолчанию:

- `grpc.trongrid.io:50051` (mainnet)
- `grpc.shasta.trongrid.io:50051` (shasta)

Используется для всех операций, которые подписывают и рассылают
транзакции (`hot send-trx`, `hot send-usdt`).
Соединение всегда **plaintext** (без TLS), что соответствует
конвенции публичных Tron‑gRPC (TronGrid сам проксирует).

### `--api-key`

Тип: строка. Передаётся:

- в HTTP‑запросах к TronGrid в заголовке `TRON-PRO-API-KEY`;
- в gRPC‑клиенте через `gc.SetAPIKey(...)` из `gotron-sdk`.

Если ключ не указан ни флагом, ни через `MONUJO_TRONGRID_API_KEY`,
запросы идут без ключа — это работает, но рейт‑лимит публичного
TronGrid очень низкий (лучше получить бесплатный ключ на
[trongrid.io](https://www.trongrid.io)).

### `--keystore-dir`

Тип: строка (путь). Алгоритм определения:

1. Если задан `--keystore-dir`, используется он (как есть).
2. Иначе если задана `MONUJO_KEYSTORE_DIR`, используется `filepath.Abs`
   от неё.
3. Иначе используется `~/.config/monujo/keystore` (`os.UserHomeDir()`).

Каталог создаётся автоматически при `wallet create`/`wallet import` с
правами `0700`. Если каталога нет, `wallet list` молча вернёт пустой
список.

В каталоге лежат JSON-файлы кошельков: зашифрованные локальные (v1/v2)
и опционально **внешние** записи только с адресом (`wallet import-external`).
Подкаталоги и прочие файлы `wallet list` пропускает без ошибок.

### `--version`

Печатает версию, как она была заложена при сборке Makefile. Формат
вывода: `<version> (<commit>)`. Без сборки через Makefile это будет
`dev (unknown)` (см. `cmd/monujo/main.go`).

```bash
monujo --version
# v0.1.0 (a1b2c3d)
```

### `--help` / `-h`

Стандартный `cobra`. На любом уровне — корневом, групповом и в
конкретной подкоманде. См. [02 — Установка](02-installation.md#где-искать-справку-самой-программы).

## Переменные окружения подробнее

### `MONUJO_TRONGRID_API_KEY`

Алиас для `--api-key`. Лидирующие/хвостовые пробелы обрезаются.
Используется, только если флаг не задан.

### `MONUJO_KEYSTORE_DIR`

Алиас для `--keystore-dir`. Перед использованием путь приводится к
абсолютному (`filepath.Abs`).

### `MONUJO_IMPORT_KEY`

Используется только в `wallet import`. Если `--key-hex` не указан или
пуст, программа берёт значение из этой переменной (с `TrimSpace`).
Если и переменной нет — выводится ошибка:

```
provide --key-hex or set MONUJO_IMPORT_KEY with the hex private key
```

Содержимое — 64 hex‑символа (опционально с префиксом `0x`,
который будет обрезан). Любые лишние символы или неверная длина
приводят к ошибке валидации; ключ из всех нулей отбрасывается как
заведомо слабый.

## Что НЕ настраивается

- **Параметры scrypt** (`N=32768, r=8, p=1`) — фиксированы в коде.
- **Лимит комиссии** для TRC‑20 транзакций (`DefaultFeeLimitSun =
  100_000_000` сан, т.е. **100 TRX**) — фиксирован в коде, во
  внешний флаг не вынесен.
- **Таймауты HTTP/gRPC** — `30s` для HTTP TronGrid и `60s` для gRPC,
  без флагов.
- **Версия зашифрованного keystore** — записывается как `2` (argon2id);
  читаются также legacy-файлы `1` (scrypt) с автомиграцией при unlock.

## Совместимость флагов между командами

Одни и те же глобальные флаги действительны для любой команды. При
этом локальные флаги конкретной подкоманды (например, `--addr`,
`--from`, `--name`, `--amount`, `--force`) описаны только у неё и
должны указываться после имени подкоманды.

Пример полной строки:

```bash
monujo --network shasta --output json --api-key "$KEY" \
       hot send-usdt --from myhot --to T... --amount 10.25 --force
```
